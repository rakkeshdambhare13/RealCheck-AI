\# RealCheck AI



\## Multimodal AI-Based Fake Media Detection and Prediction System



RealCheck AI is an AI-powered system designed to detect potentially fake or AI-generated images and videos.



\## Features



\- Image fake-media detection

\- Video fake-media detection

\- Real/Fake prediction

\- Confidence score

\- Fusion-based prediction

\- Grad-CAM visualization

\- Analysis history

\- Robustness testing



\## Technologies



\- Python

\- Streamlit

\- PyTorch

\- OpenCV

\- NumPy

\- Pandas

\- Scikit-learn

\- Computer Vision

\- Deep Learning
